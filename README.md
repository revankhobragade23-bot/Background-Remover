# 🖼️ Background Remover using Python

This is a simple Python project I made to remove the background from an image using AI.

I built this project while learning how Python libraries and AI-based tools can be used to work with images. The project takes an image as input, removes its background, and saves the final image as a PNG.

## 🚀 What It Does

- Removes the background from an image
- Uses `rembg` for AI-based background removal
- Supports HEIC images
- Saves the output as a PNG image
- Simple and easy to run

## 🛠️ Technologies Used

- Python
- rembg
- Pillow
- pillow-heif
- ONNX Runtime
